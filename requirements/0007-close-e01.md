## Implementation notes

- 0006 AC-9: the first dispatch of iOS `tests.yml` failed because `macos-latest`
  (`macos-26-arm64`) has no iOS 27.2 Simulator; the workflow now runs on `xcode-27`
  and selects `/Applications/Xcode_27.2.app` (direct change `fix-ios-ci-xcode`).
- Findings approved on 2026-11-16 (F-1 to F-11 and F-16 fixed here; F-12 to F-15 written as open
  questions of E02 and E04). What changed:
  - F-1: `backend/tests/test_backend_skeleton.py`, 25 tests for AC-1 to AC-8 of 0001
    (the app in process through `httpx.ASGITransport` on the test database).
  - F-2: Stylelint 16 (`web/stylelint.config.mjs`): no hex, named or functional
    colours, no absolute length units, font weights only through `var(--…)`, and no
    primitive tokens (`--color-*`, `--space-*`, `--radius-*`, `--font-*`, `--icon-*`);
    in `pnpm lint` (so in `checks.yml` and the web `checks`) and in the web `on_edit`
    for `.css`. Stylelint 16 because 18 needs Node 22.22 or above.
  - F-3: token group `message` (`text.color`, `error.text.color`, `gap`,
    `padding-block`) replaces `connection-error`; `Message` uses it in the three
    clients.
  - F-4: component tokens `coming-soon.padding-block`, `message.padding-block`,
    `nav.padding-block`, `nav.item.padding-block`, `button.padding-inline` and
    `connection-gate.min-height`; web CSS reads only component tokens. Values are the
    same, so no screenshot changed.
  - F-5: primitive `icon.size.md` and component `nav.icon.size` size the bell on web
    (`.item svg` in `Navigation.module.css`) and Android (`Modifier.size`); the stroke
    stays in the icon's 24-unit view box, like its path. `BellIcon` added to the
    catalog of `docs/agent/codebase-map.md`.
  - F-6: workspace check `contracts` (`python3 scripts/sync_contracts.py --check`).
  - F-7: 0005 AC-10 reworded with the user's permission.
  - F-8: `HealthNavigation.kt` (`ConnectionState`, `Connection`, `rememberConnection`,
    `ConnectionError`) and `AppConfigNavigation.kt` (`UpdateDestination`); the app
    goes through them. The Konsist rule now allows, from outside a feature, only the
    declarations of its `<Feature>Navigation.kt`; new violation fixture `Shell.kt`
    and the expected list of the AC-7 test updated (the approved test change of F-8).
  - F-9: `MainApp.isStubbedForUITests` reads `BACKEND_STUB` only under `#if DEBUG`.
  - F-10: the web BFF throws when `BUILD_NUMBER` is not set; Vercel needs the
    variable.
  - F-11: `UpdateDestination` opens `market://`, and the Play Store website when the
    device has no Play Store app.
  - F-16 (found by the user testing iOS by hand): the bell is a `Navigation` bar of one
    item at the top of `AppShell`; `Navigation` takes `arrangement` (`.spaceBetween`,
    `.end`), as on Android. With the user's permission, the 0006 UI test
    `testAC5NotificationsButtonOpensItsScreen` also checks that the bell is selected
    and Inicio is not.
